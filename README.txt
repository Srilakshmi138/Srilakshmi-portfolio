SRILAKSHMI C - PORTFOLIO

Files:
- index.html  -> main portfolio page
- style.css   -> portfolio design
- script.js   -> small interactions
- assets/resume/Srilakshmi_Shetty_Resume.pdf -> resume used by both Resume buttons

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in a browser.
3. The Download Resume buttons point to the included PDF using a relative path, so the file works when the complete folder is kept together.

IMPORTANT:
Do not move or rename the resume PDF unless you also update the href path in index.html.
